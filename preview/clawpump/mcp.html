MCP

One URL. 132 tools.

Add ClawPump as a connector and your AI client can swap, trade perps, launch tokens and run your agents. Sign in once — there is no key to copy.

  • Desktop browser or the desktop app
  • Any plan — Free allows one custom connector
  • Team and Enterprise: owners only
  1. 01

    Copy the connector URL.

    https://mcp.clawpump.tech/mcp
  2. 02

    Open Claude's connector settings. The URL arrives filled in — review it, then click Add.

    Open Claude with the URL filled in

    You still review the values and confirm before anything is added.

  3. 03

    Adding it by hand instead: go to Customize → Connectors (shown as Settings → Connectors on some accounts), click Add custom connector, and paste the URL.

  4. 04

    Click Connect and sign in with Google or X. Check the permissions before you approve.

  5. 05

    In a chat, click + near the message box, open Connectors, and switch ClawPump on for that conversation.

Worth knowing

You never copy a key

Signing in issues a credential that stays encrypted inside your client's access token. It is never shown to you and never shown to the client.

One client at a time

Connecting a second client signs the first one out. Reconnect there when you want to switch back — your agents and balances are untouched.

Sign in as the account that owns your agents

Tools act on the agents in the ClawPump account you authorize with. Use Google or X, whichever you signed up with.

Prefer to run the server yourself?

@clawpump/agents runs locally over stdio with an API key instead of a connector. Create a key in the dashboard, then follow the install steps in the docs.
