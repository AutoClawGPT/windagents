# WindAgents

Aeolian Forge — 3D tokenized meme-coin agent platform for Solana.

- Stack: Next.js 16 · React 19 · Tailwind v4 · R3F · GSAP/Lenis-ready · libSQL
- Integrations: ClawPump (`cpk_`), PayBox (`pbx_`), Jupiter, Helius
- Design: see `DESIGN.md` — original spatial HUD, **not** an AnsemRail clone

```bash
npm install
npm run dev -- -p 3000
```

Skill doc: http://localhost:3000/skill.md
